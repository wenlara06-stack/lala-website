# 拉拉的網站　使用說明

⚠️ **重要提醒**：這個網站現在改成用「後台系統」讀取資料，
**不能再用「雙擊 index.html」在本機直接打開來測試**（會看到空白頁，這是正常的，不是壞掉）。
從現在開始，測試網站都要用**部署後拿到的正式網址**（例如 `xxx.netlify.app`）。
本機測試的方式只剩下我另外提供的「單一預覽檔」可以用（那個是特別做的離線版本）。

---

## 一、整體架構說明（花 2 分鐘看一下，之後會比較清楚）

- 網站的樣子（版面、配色）在 `css/style.css`，一般不用動
- 網站的行為（選單、搜尋、渲染文章）在 `js/main.js`，一般不用動
- **文章內容**放在 `data/articles.json`
- **五個分類設定**放在 `data/categories.json`
- 後台系統（`admin/` 資料夾）就是專門用來「編輯這兩個 JSON 檔案」的一個好用介面，
  你不用直接打開 JSON 檔案改，用後台的表單填寫就好

---

## 二、部署步驟（一定要照順序做，後台系統才能運作）

跟之前教的「拖曳資料夾到 Netlify」不一樣，這次要用「連接 GitHub」的方式部署，
後台系統才能把你寫的文章自動存回去。

### Step 1：申請 GitHub 帳號、建立倉庫（repository）

1. 到 [github.com](https://github.com) 註冊一個免費帳號
2. 右上角「+」→「New repository」
3. Repository name 隨意取（例如 `lala-website`），設為 **Public**，其他預設就好，按「Create repository」
4. 進到新建立的空倉庫頁面，會看到「uploading an existing file」的連結，點下去
5. 把整個網站資料夾**裡面的所有檔案**（不是資料夾本身，是打開資料夾後裡面的東西）拖曳上傳，
   下方填寫任何說明文字，按「Commit changes」

### Step 2：到 Netlify 用「連接 Git」的方式部署

1. 到 [netlify.com](https://www.netlify.com) 註冊/登入
2. 「Add new site」→「Import an existing project」
3. 選擇「Deploy with GitHub」，授權後選擇剛剛建立的 `lala-website` 倉庫
4. 其他設定不用改，直接按「Deploy」
5. 完成後會拿到一個網址，例如 `random-name-123.netlify.app`，這就是你的正式網站網址

### Step 3：開啟 Identity（身分驗證），讓你能登入後台

1. 在 Netlify 網站後台，進入你的專案 → 上方選單「Site configuration」→ 左側「Identity」
2. 按「Enable Identity」
3. 往下找到「Registration preferences」，選成 **Invite only**（只有你邀請的人能登入，比較安全）
4. 再找到「Services」→「Git Gateway」，按「Enable Git Gateway」（這一步讓後台能把你寫的東西存回 GitHub）

### Step 4：邀請自己成為後台使用者

1. 一樣在 Identity 頁面，找到「Invite users」
2. 輸入你自己的 email，送出邀請
3. 去收信，信裡有一個連結，點開後會導到你的網站，請你設定密碼
4. 設定完成後，你就是這個網站的後台使用者了

### Step 5：開始使用後台寫文章

1. 打開 `你的網址/admin`（例如 `random-name-123.netlify.app/admin`）
2. 用剛剛設定的帳號密碼登入
3. 左邊選單有「📝 文章」和「🗂 五個分類設定」
4. 點「文章」→「所有文章」，會看到目前所有文章的清單，可以直接編輯，也可以按「Add」新增一筆
5. 每篇文章可以填：標題、分類（下拉選單選）、日期、摘要、封面圖（直接從電腦選圖上傳）、
   內文（打字、設定標題/粗體/清單、插入圖片，操作很接近 Word 或 Notion）
6. 填完按右上角「Publish」，大概 30 秒到 1 分鐘後，網站就會自動更新，完全不用碰任何程式碼

## 三、如果還沒設定好後台，想先手動改文章內容

打開 `data/articles.json`，裡面是一個陣列，每一篇文章長這樣：

```json
{
  "id": "取一個英文或數字的代號，例如 article-011",
  "title": "文章標題",
  "category": "money",
  "date": "2026-07-12",
  "readTime": "6 分鐘",
  "excerpt": "文章的一兩句話摘要，會顯示在列表卡片上。",
  "cover": "images/art/cat-money.jpg",
  "content": "這裡放文章內文，可以用 Markdown 語法，例如 ## 小標題、**粗體**、> 引言",
  "draft": false
}
```

複製一整組貼在陣列最上面，改內容、存檔，上傳更新後就會生效。

### 分類代碼對照表

| category 代碼 | 對應的分類 |
|---|---|
| `money` | 學著把錢想清楚（理財規劃） |
| `love`  | 把愛好好留下來（世代傳承） |
| `grace` | 學著從容過日子（優雅生活） |
| `aging` | 照著想要的方式老去（退休安養） |
| `care`  | 學著照顧自己（客戶理賠） |

### content 可以用的 Markdown 語法

- `## 小標題`
- `**粗體文字**`
- `> 金句引言`
- `- 項目一` `- 項目二`（條列清單）
- 也可以直接寫 HTML 標籤（例如 `<p>`、`<h2>`），系統一樣看得懂

## 四、如何換掉「關於我」的照片

打開 `about.html`，搜尋 `about-photo` 這個區塊，把 `img` 的 `src` 換成你的新照片檔名即可，
記得把照片放進 `images` 資料夾。

---

## 五、如何換掉 LINE 預約連結

網站裡目前都是暫時的 `https://line.me/R/ti/p/@yourlineid`，
用「尋找並取代」把所有檔案裡的這串網址換成你真正的 LINE 官方帳號連結即可。
共有 5 個檔案要換：`index.html`、`about.html`、`articles.html`、`article.html`、`js/main.js`。

---

## 六、如何設定「email 訂閱」功能

網站每一頁最下面都有一個訂閱表單。因為這是純網頁，需要串接免費電子報工具，推薦 **Mailchimp**：

1. 到 [mailchimp.com](https://mailchimp.com) 免費註冊
2. 建立一個 Audience（受眾名單）
3. Audience 設定裡找「Signup forms」→「Embedded forms」，複製表單網址
4. 網址長得像：`https://xxxx.usX.list-manage.com/subscribe/post?u=...&id=...`
5. 用「尋找並取代」，把網站 4 個 html 檔案裡的
   `https://YOUR-ACCOUNT.usX.list-manage.com/subscribe/post?u=YOUR_U&id=YOUR_ID`
   換成你剛剛複製的真正網址
6. 之後想寄文章給訂閱者，就在 Mailchimp 後台寫一封 Campaign 寄出即可

## 七、檔案結構說明

```
index.html            首頁
about.html             關於我
articles.html          文章列表（含搜尋、分類篩選）
article.html           單篇文章閱讀頁
css/style.css          網站樣式（配色、字體、版面）
js/main.js              網站互動邏輯
data/articles.json     ★ 所有文章內容，後台系統會自動編輯這個檔案
data/categories.json   ★ 五個分類設定，後台系統會自動編輯這個檔案
admin/                  後台系統設定（index.html + config.yml），一般不用動
images/                 照片資料夾
```
